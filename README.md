# 📝 BOM to PE3 Converter (ГОСТ Перечень элементов)

Скрипт на Python 3 для автоматической генерации текстового документа «Перечень элементов» (ПЭ3) из файлов BOM (Bill of Materials) САПР **Cadence Allegro** и **Mentor Graphics PADS**. 

Утилита автоматически группирует компоненты, записывает их диапазонами (например, `R1-R10`), подставляет штамп (основную надпись) по ГОСТ через ODT-шаблон, динамически сжимает слишком длинный текст и генерирует готовые форматы `.odt` и `.pdf`.

---

## ✨ Ключевые возможности

- **Поддержка популярных САПР:** Полноценный разбор структуры файлов спецификаций, выгруженных из сред проектирования Cadence Allegro и Mentor Graphics PADS.
- **Умное автоопределение формата:** Скрипт анализирует структуру входного файла (табулированный текст Cadence Allegro или табличный отчет PADS с разделителями `|`) и автоматически выбирает нужный парсер. Также доступно принудительное указание формата через параметры командной строки.
- **Группировка по ГОСТ 2.701:** Компоненты сортируются в алфавитно-цифровом порядке, разбиваются на категории с заголовками (Резисторы, Конденсаторы, Микросхемы и т.д.) и объединяются в непрерывные диапазоны.
- **Автоматическая обработка DNP (неустанавливаемых элементов):** Скрипт сканирует текстовые поля на наличие метки `DNP` (Do Not Populate) без привязки к регистру. При её обнаружении строка наименования компонента автоматически заменяется на корректную по ГОСТ формулировку **«не устанавливается»**.
- **Умное заполнение штампа:** Данные разработчиков, децимальный номер, инвентарные номера и литера автоматически прописываются в основную надпись документа.
- **Динамический автоподгон текста:** Если наименование компонента или позиционное обозначение не влезает в границы ячейки, скрипт автоматически применяет пропорциональное горизонтальное сжатие (`text-scale`), предотвращая излом строк.
- **Учет специфики первой страницы:** Строки «Удостоверен ...» и «Имя файла ...» автоматически сдвигаются в самый низ первой страницы прямо перед штампом.
- **Двойной экспорт:** На выходе формируется редактируемый файл LibreOffice Writer (`.odt`), а в фоновом режиме запускается сборка финального `.pdf`.

## 🛠 Требования к окружению

Для работы скрипта необходимы:
1. **Python 3.x** (используются только стандартные библиотеки: `zipfile`, `xml`, `json`, `argparse`, `re`).
2. **LibreOffice** (должен быть установлен в системе и доступен через терминал по команде `libreoffice` для фоновой конвертации в PDF).

## 📂 Структура ключевых файлов проекта

- `bom_to_pe3.py` — основной исполняемый Python-скрипт.
- `Перечень элементов.odt` — готовый ODT-шаблон, содержащий рамки, ГОСТ-штампы, настроенные стили и текстовые маркеры-плейсхолдеры (`{Наименование}`, `{Разработал}`, `{Инвномер}`).
- `params.json` — конфигурационный файл для заполнения штампа и метаданных документа.

## 🚀 Быстрый запуск

### 1. Подготовка конфигурации (params.json)
Отредактируйте файл параметров, указав децимальный номер вашей платы, название изделия и фамилии проверяющих:

```json
{
  "document_designation": "АБВГ.XXXXXX.XXX",
  "product_name": "Блок управления",
  "literature": "О",
  "developer": "Иванов И.И.",
  "checker": "Петров П.П.",
  "standard_control": "Сидоров С.С.",
  "approver": "Кузнецов К.К.",
  "inventory_number": "1234",
  "first_application": "АБВГ.XXXXXX.XXX",
  "version": "01"
}
```

### 2. Запуск генерации
Для запуска с **автоматическим определением формата** BOM (Cadence Allegro или Mentor Graphics PADS) выполните команду:

```bash
python3 bom_to_pe3.py input_bom.txt -t "Перечень элементов.odt" -p params.json
```

Если вам необходимо **принудительно задать формат** файла (например, для PADS), используйте флаг `-f`:

```bash
python3 bom_to_pe3.py input_bom.txt -f pads -t "Перечень элементов.odt" -p params.json
```

### 3. Результат
После выполнения команды в папке проекта появятся:
- **`АБВГ.XXXXXX.XXXПЭ3-В01.odt`** — документ Перечня элементов со вставленной таблицей.
- **`АБВГ.XXXXXX.XXXПЭ3-В01.pdf`** — готовый для печати документ (сгенерированный в фоне через headless-режим LibreOffice).

## ⚙️ Параметры командной строки

```text
Позиционные аргументы:
  bom_file              Путь к исходному текстовому файлу BOM (Cadence или PADS)

Опциональные аргументы:
  -h, --help            Показать справку по командам
  -t , --template       Путь к ODT-шаблону с рамкой (по умолчанию: "Перечень элементов.odt")
  -o , --output         Явно задать имя выходного ODT файла (по умолчанию формируется из децимальника)
  -f , --format         Принудительно выбрать формат входного файла: "cadence" или "pads" 
                        (по умолчанию парсер определяется автоматически на основе структуры текста)
  -p , --params         Путь к JSON файлу с параметрами штампа (по умолчанию используются базовые настройки)
```

## 🔍 Маркеры автоматической подстановки в шаблоне

Скрипт ищет внутри структуры ODT-файла (`content.xml` и `styles.xml`) следующие текстовые метки и заменяет их на переменные из JSON:
- `{Наименование}` ➔ Название изделия (`product_name`)
- `{Разработал}`, `{Проверил}`, `{НКонтроль}`, `{Утвердил}` ➔ Фамилии исполнителей
- `{Л}` ➔ Литера документа (`literature`)
- `{Инвномер}` ➔ Инвентарный номер (`inventory_number`)
- `{Первпримен}` ➔ Первичное применение (`first_application`)
- Закладка `{Децимальный номер}` ➔ Полный шифр документа вида `АБВГ.XXXXXX.XXX ПЭ3`
